# 207_SoxExtras
Private Git for Socks' Extra additions and QoL Tweaks for Detachment 207

# Mission Statement
This expansion aims to add or modify content within the D207 modpack to improve player quality of life (QoL). This can be achieved through development and deployment of custom camos, custom items, or custom ammo/items. The expansion aims to be as lightweight as possible, without interfering with other core elements of the D207 modset.

# Current Content and Changelog
## V1.0 
- Migrated from 207_Gear_Expac repo
### Content
- 8x Vanilla G3 Camo variants, based on AMCU, AMPU, AMCS, AMCT
- 12x Balaclavas with skull decals
- 12x Variants of the ADFRC Team Wendy Exfils, with custom patches for each 207 section
- 6x New ammo variants for 5.56mm, 7.62mm, .338LM, .300WM, and .50BMG
